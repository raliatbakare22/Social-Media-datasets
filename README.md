# Mint Classics Exploratory Data Analysis

## Overview
This project analyzes the Mint Classics dataset to uncover insights into sales performance, customer behavior, and inventory trends.

## Tools Used
- SQL (data cleaning & transformation)
- Power BI (visualization)

## Key Insights
- Identified top-selling products and low-performing items
- Analyzed yearly sales trends
- Evaluated warehouse inventory levels
- Assessed sales representative performance

## Files
- SQL query outputs (.csv files)
- Power BI dashboard (.pbix)
- Full analysis report (.docx)

## How to View
Download the .docx file or view CSV outputs for insights.
